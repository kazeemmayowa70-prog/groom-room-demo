# The Groom Room — Premium Barber Studio Website

A premium barber studio website demonstration built with HTML, CSS and JavaScript.

**Live Website:** https://kazeemmayowa70-prog.github.io/groom-room-demo/

## Project Overview

The Groom Room is a demonstration website showing how a modern barber business could present its services, display haircut photography and encourage customer enquiries.

The design uses a luxury black-and-gold visual identity with a responsive layout.

## Features

- Premium black-and-gold design
- Responsive mobile layout
- Mobile navigation menu
- Hero section
- Barber services and sample prices
- Haircut and grooming image gallery
- WhatsApp enquiry button demonstration
- Automatically updated copyright year

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Important Demo Notes

This is a portfolio demonstration, not a verified operating barber business.

- Service prices are sample prices.
- The WhatsApp number is a placeholder.
- Image permissions must be verified before commercial use.
- No real appointment management or payment system is implemented.
